# DB Desk (moved)

This repository is retired. DB Desk now lives in one place:

**[github.com/wzul/dbdesk-app](https://github.com/wzul/dbdesk-app)**

The desktop app, the Hermes plugin and the website share that repository, and the
plugin is generated from the app sources (`scripts/build-plugin.py`) so the two
cannot drift apart. Grab `dbdesk-plugin-<version>.zip` from the
[latest release](https://github.com/wzul/dbdesk-app/releases/latest) and unzip it
into `~/.hermes/plugins/dbdesk`.
